⚡ 1. C++ (Arduino Microcontrollers)

Low-level programming language used to program physical boards like Arduino, ESP8266, and ESP32.

// Arduino C++ Digital Output Example
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

🐍 4. Python (AI & MicroPython)

Powering robotics algorithms, computer vision, data pipelines, and MicroPython board automation.

# MicroPython Distance Logic Example
from machine import Pin
import time

led = Pin(2, Pin.OUT)
distance = 15

if distance < 20:
    print("Obstacle Detected!")
    led.value(1)
else:
    led.value(0)
